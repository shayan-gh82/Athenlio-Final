# Athenlio - Final Full-Stack Delivery

این بسته شامل نسخه نهایی فرانت‌اند Next.js و بک‌اند Django پروژه Athenlio است.

- راه‌اندازی مرحله‌به‌مرحله: `RUN_GUIDE.md`
- معماری و قرارداد بخش‌ها: `ARCHITECTURE.md`
- نتیجه تست‌ها و تطبیق نیازمندی‌ها: `FINAL_VALIDATION_REPORT.md`

پوشه‌ها:

- `frontend`: رابط دوزبانه فارسی/انگلیسی روی پورت 5173
- `backend`: API، دیتابیس SQLite، Media و Django Admin روی پورت 8000

قابلیت‌های تکمیلی این نسخه شامل سبد خرید دوره‌ها، صفحات مستقل «دوره‌های من» و «خریدها»، ویرایش کامل پروفایل و تصویر مدرس و فیلتر دوره‌های مدرس تأییدنشده است.

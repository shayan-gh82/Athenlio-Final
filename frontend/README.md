# Athenlio

Athenlio یک پلتفرم دوزبانه برای کشف دوره‌ها و استادان زبان، ثبت‌نام در دوره و مدیریت مسیر یادگیری است. رابط از ابتدا برای فارسی RTL و انگلیسی LTR طراحی شده و عملیات حساب و داده با اتصال بک‌اند Django انجام می‌شوند.

## امکانات فعلی

- صفحه اصلی دوزبانه با مسیرهای هم‌وزن «دوره‌ها» و «استادان»
- فهرست دوره‌ها با جست‌وجو، فیلتر، مرتب‌سازی، URL قابل اشتراک و فیلتر موبایل
- فهرست و صفحه جزئیات استاد، دوره و مقاله
- ثبت‌نام و ورود متصل به session بک‌اند، همراه با بازگشت امن به مقصد قبلی
- داشبورد دانشجو، ویرایش پروفایل و بارگذاری تصویر
- onboarding و داشبورد مدرس، مدیریت دوره و بررسی درخواست‌های ثبت‌نام
- تم روشن و تاریک، طراحی واکنش‌گرا، RTL/LTR و کاهش حرکت براساس تنظیم سیستم
- متادیتای دوزبانه، canonical/hreflang، sitemap و robots برای مسیرهای عمومی

## فناوری‌ها

- Next.js 16 App Router (اجرای توسعه و build با خود Next.js)
- React 19 و TypeScript
- Tailwind CSS 4 و کامپوننت‌های Shadcn/Base UI
- TanStack Query برای server state
- Redux Toolkit برای session و state رابط
- Axios با refresh-cookie flow
- React Hook Form و Zod برای فرم‌ها و اعتبارسنجی

## اجرای محلی

پیش‌نیاز: Node.js `22.13.0` یا جدیدتر و بک‌اند Django در حال اجرا روی پورت `8000`.

macOS / Linux:

```bash
npm run install:ci
cp .env.example .env.local
npm run dev
```

Windows PowerShell:

```powershell
npm ci
Copy-Item .env.example .env.local
npm run dev
```

متغیرهای محیطی:

```env
NEXT_PUBLIC_API_BASE_URL=http://localhost:8000
NEXT_PUBLIC_SITE_URL=http://localhost:5173
```

`NEXT_PUBLIC_API_BASE_URL` را بدون اسلش پایانی تنظیم کنید. اگر این مقدار خالی باشد، سایت در Preview Mode اجرا می‌شود و mutationها غیرفعال می‌مانند.

فرانت در `http://localhost:5173/fa` و مستندات API بک‌اند در `http://localhost:8000/api/schema/swagger-ui/` در دسترس‌اند.

## کنترل کیفیت

```bash
npm run typecheck
npm run lint
npm run build
npm test
```

`npm test` قراردادهای احراز هویت، فیلترهای دوره، HTML خروجی، SEO، نرمال‌سازی پاسخ قدیمی مدرس و اجزای رابط را بررسی می‌کند.

نسخه نهایی بک‌اند همراه پروژه ارائه شده و قرارداد API لازم را در خود دارد؛ نیازی به اجرای اسکریپت Patch جداگانه نیست.

## سناریوی تست دستی برای ارزیابی

1. بک‌اند را روی پورت `8000` و سپس فرانت را روی پورت `5173` اجرا کنید.
2. صفحه اصلی، دوره‌ها، استادان و بلاگ را بدون ورود در هر دو زبان بررسی کنید.
3. از `/fa/register/student` حساب دانشجو بسازید؛ داشبورد و صفحه ویرایش پروفایل باید باز شوند.
4. از یک دوره، ثبت‌نام را انتخاب کنید؛ برای ادامه باید وارد شوید و سپس مبلغ، واحد پول و تصویر رسید را ارسال کنید.
5. وضعیت ثبت‌نام را در داشبورد دانشجو و تغییر آن را پس از بررسی ادمین Django کنترل کنید.
6. از `/fa/register/tutor` حساب مدرس بسازید و فرم چندمرحله‌ای پروفایل، تصویر و ویدیوی معرفی را تکمیل کنید.
7. پیش از تأیید مدرس، ساخت و مدیریت دوره باید در رابط محدود باشد؛ پس از تأیید در Django Admin، داشبورد کامل فعال می‌شود.
8. در پایان `npm run lint` و `npm test` را اجرا کنید.

## اتصال بک‌اند

بک‌اند Django پروژه‌ای جدا و از پیش ارائه‌شده است و سورس آن در این مخزن فرانت‌اند تکرار نشده است. این بک‌اند از احراز هویت cookie-based استفاده می‌کند. برای اتصال واقعی باید موارد زیر در سرور تنظیم شوند:

- CORS و CSRF برای origin فرانت
- cookie امن با `SameSite` و `Secure` متناسب با محیط
- endpointهای login، refresh، logout و `me`
- media hosting برای تصاویر پروفایل، دوره و رسید
- حساب‌های تست دانشجو، مدرس تأییدشده و مدیر

مسیر بازیابی رمز فعلی و endpointهای فاقد object ownership عمداً در فرانت فعال نشده‌اند. اصلاح امنیتی بک‌اند باید در commit جداگانه، همراه با تست مجوز منفی انجام شود.

فایل `.env.local` در پروژهٔ قابل اجرا وجود دارد، اما در ZIP نهایی عمداً حذف می‌شود؛ در صورت نیاز آن را از `.env.example` بسازید و API را روی پورت ۸۰۰۰ نگه دارید.

## ساختار اصلی

```text
app/          مسیرها، layoutها و metadata
components/   اجزای مشترک، برند و navigation
features/     قابلیت‌های مستقل auth، course، tutor، student و blog
lib/          API client، قرارداد endpointها، auth helpers و SEO
messages/     ترجمه‌های فارسی و انگلیسی
docs/         نقشه راه ادمین و چک‌لیست انتشار
tests/        تست‌های قرارداد و خروجی build
```

# چک‌لیست انتشار Athenlio

این سند دو Gate جدا دارد: «تحویل نسخه تمرینی» و «انتشار محصول واقعی». علامت‌های بخش اول پس از هر release دوباره کنترل می‌شوند؛ بخش دوم تا آماده‌شدن بک‌اند تولید عمداً باز می‌ماند.

## Gate نسخه تمرینی و پورتفولیو

- [x] برند Athenlio و لوگوی نهایی در همه مسیرهای اصلی یکسان است.
- [x] فارسی RTL زبان پیش‌فرض و انگلیسی LTR قابل انتخاب است.
- [x] صفحات Home، Courses، Tutors و Blog بدون ورود قابل پیش‌نمایش‌اند.
- [x] عملیات حساب، پروفایل، ثبت‌نام دوره و داشبورد بدون API mutation واقعی انجام نمی‌دهند.
- [x] صفحات ورود، ثبت‌نام و داشبورد `noindex` هستند.
- [x] canonical، hreflang، sitemap و robots برای صفحات عمومی تعریف شده‌اند.
- [x] تم روشن/تاریک، موبایل، کیبورد و حالت reduced-motion در طراحی لحاظ شده‌اند.
- [x] lint بدون خطا اجرا شده است.
- [x] build و تمام تست‌های خودکار موفق‌اند.
- [x] مسیرهای اصلی در مرورگر دسکتاپ بدون خطای runtime برنامه بررسی شده‌اند.
- [x] نسخه نهایی روی Sites منتشر و لاگ Worker کنترل شده است.

## Gate اتصال بک‌اند واقعی

- [ ] URL قطعی API برای محیط staging و production ثبت شده است.
- [ ] CORS، CSRF، cookie و HTTPS روی دامنه نهایی تست شده‌اند.
- [ ] حساب تست دانشجو، مدرس تأییدشده و ادمین آماده است.
- [ ] مسیر کامل register → login → profile → enrollment تست end-to-end دارد.
- [x] آپلود تصویر پروفایل، تصویر دوره، ویدیوی معرفی و رسید روی بک‌اند محلی تست شده است.
- [x] وضعیت Enrollment پس از mutation دوباره دریافت و با پاسخ سرور همگام می‌شود.
- [ ] خطاهای 400، 401، 403، 404، 429 و 5xx پیام قابل‌فهم دوزبانه دارند.
- [ ] endpoint فهرست مدرس فقط مدرس‌های تأییدشده را نمایش می‌دهد.

## Gate امنیت پیش از فروش یا انتشار عمومی

- [ ] تغییر رمز فقط با توکن یک‌بارمصرف معتبر انجام می‌شود.
- [ ] ساخت Blog برای مهمان و نقش‌های غیرمجاز در بک‌اند رد می‌شود.
- [ ] object ownership برای Student، Tutor، Enrollment، Lesson و Blog enforce و تست شده است.
- [ ] secretها از سورس حذف، rotate و از environment امن خوانده می‌شوند.
- [ ] rate limiting برای login، ثبت‌نام، بازیابی رمز و upload فعال است.
- [ ] لاگ‌ها شامل رمز، توکن، cookie یا اطلاعات حساس کاربر نیستند.
- [ ] dependency و security scan بدون آسیب‌پذیری بحرانی باز است.
- [ ] backup، restore و سیاست نگهداری داده آزمایش شده است.

## Gate پنل ادمین و پشتیبانی

- [ ] RBAC واقعی برای Support، Moderator، Admin و Super Admin در بک‌اند وجود دارد.
- [ ] تیکت کاربر، پیام، moderation و audit endpoint امن دارند.
- [ ] MFA برای نقش‌های مدیریتی فعال است.
- [ ] عملیات حساس دارای actor، زمان، دلیل و before/after در audit log هستند.
- [ ] تست مجوز منفی ثابت می‌کند هر نقش به عملیات خارج از دسترسی خود نمی‌رسد.

جزئیات اجرایی این بخش در [نقشه راه پنل ادمین](ADMIN_PRODUCT_ROADMAP_FA.md) آمده است.

## تصمیم انتشار

- نسخه تمرینی وقتی قابل تحویل است که همه موارد Gate اول تیک خورده باشند.
- نسخه عمومی یا قابل فروش تا تکمیل سه Gate بعدی نباید منتشر شود.
